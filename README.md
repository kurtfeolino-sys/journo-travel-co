# Journo Travel Co.

A modern, responsive newsletter website for Journo Travel, featuring expert travel tips, destination inspiration, insider strategies, and curated stories to help travelers save more, experience more, and stress less.

## Project structure

```text
journo-travel-co/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Preview locally

Open `index.html` in a browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Upload all project files to the root of the GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages** under **Code and automation**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save and wait for the deployment to finish.

The site will be available at:

`https://kurtfeolino-sys.github.io/journo-travel-co/`
